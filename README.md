## 3. Mục đích của trang
Trang web được xây dựng nhằm thông báo cho người dùng khi có nguy cơ mất nội dung chưa được lưu. Trang giúp người dùng xác nhận trước khi loại bỏ thay đổi, đồng thời cung cấp lựa chọn tiếp tục chỉnh sửa hoặc đóng hộp thoại.

## 4. Các chức năng chính
- Hiển thị hộp thoại xác nhận hủy thay đổi chưa lưu.
- Hiển thị biểu tượng cảnh báo và nội dung lưu ý.
- Cho phép người dùng tiếp tục chỉnh sửa.
- Cho phép người dùng loại bỏ thay đổi và đóng hộp thoại.
- Cho phép đóng hộp thoại bằng nút đóng ở góc phải.
- Cho phép đóng hộp thoại bằng phím `Escape`.
- Hiển thị thông báo Toast sau khi người dùng thao tác.
- Tự động ẩn thông báo Toast sau 3 giây.
- Hỗ trợ hiển thị trên màn hình điện thoại và máy tính.

## 5. Công nghệ sử dụng
- **HTML5:** Xây dựng cấu trúc và nội dung trang web.
- **CSS3:** Thiết kế giao diện, bố cục, màu sắc, hiệu ứng và khả năng đáp ứng trên các kích thước màn hình.
- **JavaScript:** Xử lý sự kiện nhấn nút, phím Escape, đóng hộp thoại và hiển thị thông báo Toast.

## Cấu trúc thư mục

- `cse_gk.html`: File giao diện HTML.
- `cse_gk.css`: File định dạng giao diện CSS.
- `cse_gk.js`: File xử lý chức năng JavaScript.
- `README.md`: File giới thiệu đề tài và hướng dẫn sử dụng.

## Hướng dẫn chạy chương trình
1. Tải hoặc sao chép toàn bộ các file vào cùng một thư mục.
2. Mở thư mục bằng Visual Studio Code.
3. Mở file `cse_gk.html` bằng trình duyệt hoặc sử dụng tiện ích Live Server.
4. Nhấn các nút trên hộp thoại để kiểm tra chức năng.

**Lưu ý:** Đây là giao diện mô phỏng. Chức năng loại bỏ thay đổi hiện đóng hộp thoại và hiển thị thông báo, chưa thực hiện xóa dữ liệu thực tế.
